  1. 28 Oct 202614:27 UTC
    Improved

    Old keys turn off when you reconnect

    Running setup again now turns off the access keys this computer no longer uses, including those of folder setups you switch. Keys still in use are left alone, and turned-off keys stay listed as revoked under Connections.

    PR #6087f3b32

    PR #58325b979
